# 数据集备选

更新：2026-10-17。用途：重建实验任务，比较模型与真人行为；暂不用于训练或 Persona 初始化。

**当前状态：主数据集未定。优先要求任务直接涉及社会规范条件并有对应真人行为，再核查公开模型基线与评价协议。BehaviorBench 普通分配任务单独作为主实验扣题不足；Raihani 的规范条件贴题，但同数据 LLM 基线尚未查实。**

### 采用前需要明确

- BehaviorBench 的首轮任务不是全都属于一次性博弈；原文部分题目告知总轮数，重建时保留这种预期。每游戏约 200 条人类记录也不等于 200 个独立情境。
- 分配、合作等可作为规范相关行为，但单靠该子集不能估计“加入规范信息”的人机处理效应；需要对应真人条件才能支持这种结论。
- 优先只选 1–2 个任务核验，不同时展开多个基准；不改变已与导师确定的题目。
- BehaviorBench 数据卡标注 CC BY-NC-ND 4.0，代码仓库标注 MIT；两者分别记录，原始数据不随代码默认公开。

## 第一轮：公开实验数据

**Benchmark 定位补充**：本次检索尚未找到这 5 份具体数据被多个独立团队作为统一 LLM 行为评测基准反复使用的充分证据，暂按“公开人类实验数据”定位。经典博弈任务、论文被引用和数据成为通用 benchmark 是不同概念；首选排序依据题目适配性，不是 benchmark 普及度。Raihani（2014）在[2025 年后续研究](https://doi.org/10.1371/journal.pone.0321547)中被讨论，但这不等于原数据被用作统一评测集。

## 核验状态与使用边界

- 第一轮核查读取了前 3 项论文及 3 个 Zenodo 仓库页面，确认研究与数据入口；当时未下载解析原始数据。后续已独立读取 Raihani 的 XLSX 与 S1 附件。用户材料中的“3 个 CSV 已核验”仍属于此前搜索记录。
- Raihani 与 Liu 的论文页面有 CC BY 声明和官方数据附件；采用前检查附件是否另有声明。3 个 Zenodo 页面本次未显示具体许可名称，保留待核实，不能据此认定没有许可。
- 合作行为不自动等于规范行为；反馈、收益或群体规模效应也不能直接证明规范内化。Raihani 的目标金额同时改变规范门槛与达标成本，不是独立操纵纯成本。
- 固定真人历史回放只能评价给定历史下的模型选择，不能直接证明自主多轮互动的拟真性。

## 现成结果核查（2026-10-16）

- **Raihani（2014）**：原论文有真人行为分布和规范效应结果。按题名、作者、DOI 与 LLM／GPT／ChatGPT 等组合检索，并检查相关 LLM 博弈论文后，本次仍未找到直接使用这六组数据的已核实公开 LLM 成绩；不是断言从未有人使用。后续[2025 年规范研究](https://doi.org/10.1371/journal.pone.0321547)引用了它，但开展的是新真人实验，不能算同数据 LLM 基线。
- **BehaviorBench**：[论文 v3 附录 F、表 7](https://arxiv.org/html/2606.24162v3)有首轮单次行为模拟的分游戏结果。独裁者任务 Wasserstein 距离（越小越好）：Qwen3-4B 21.3、Llama3.3-70B 20.1、DeepSeek V3.2 13.7、GPT 4.1 25.8。均为论文报告值，本项目尚未运行模型复现；仅代表这一子任务，不是全基准成绩。官方评分代码可用，独立广泛采用仍未证实。
- **Dictator Game Benchmark（2025）**：[论文](https://doi.org/10.1038/s41598-025-01715-7)报告了 GPT-4 等模型结果；标准任务中真人平均给付 30.7%，GPT-4 预测 42.6%。原协议是预测人群分布，不能把 Agent 单次选择采样直接当成同协议成绩。
- **提升的证据**：固定任务、数据、模型版本、采样和评分设置，重跑公开基线并比较改进方案；结果应包含不确定性。没有成熟 benchmark 也可建立任务内对照，但只能支持限定条件下相对该基线的改进，不能直接宣称超过已有方法或证明普遍拟人性。
