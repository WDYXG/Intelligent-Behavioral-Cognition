# BehaviorBench 独裁者博弈核验

日期：2026-10-16。结论：**数据可读取，官方任务评分已离线跑通，可作为起步任务；尚未开展模型实验，也未最终确定主实验。**

## 数据与任务

- 200 条真人选择记录，只有 **1 套相同题目**；文件无参与者标识，不能独立核实去重人数或恢复个体轨迹。
- 任务：分配 100 美元，决定给接收者多少；接收者被动接受。此题文本没有后续轮次或规范信息处理组。
- `system`、`user` 是模型输入；`assistant` 是真人参照，只用于评分，不能发送给模型。
- 人类给付范围 0–80，均值 24.715，中位数 25；40 条给付为 0，31 条恰为 50。均为此测试文件的描述统计，不外推到全部人群。

## 离线评分检查

运行官方 `GameBehaviorTask`，使用人工指定的输出，执行期间禁用网络；研究模型 API 调用为 **0**。这不是完整官方 CLI 验收。

| 样例 | 检查结果 |
|---|---|
| 将真人标签本身作为评分夹具 | Wasserstein 距离为 0；仅验证评分，不是模型成绩 |
| 全部输出 50 | 距离 25.815，与独立计算吻合 |
| 全部输出 0 | 距离 24.715，与独立计算吻合 |
| 越界与不可解析输出混合 | 150 截为 100，−10 截为 0；无数字文本被排除并计为解析失败 |
| 全部无法解析 | 返回空指标，失败率 100%；不能当作距离为 0 |

官方配置将行动范围与评分范围都设为 0–100；本任务的原始和归一化 Wasserstein 数值相同，越小越接近，不能当成准确率。

## 实验设计需要注意

- 官方解析较宽松：没有括号时会取文本中的第一个数字。例如提到预算 100 但表示无法决定，仍可被解析为 100。正式实验应同时报告原始输出、格式有效率、越界率和官方评分，不能悄悄修改规则后仍称完全复现官方协议。
- 官方还输出分箱后的 KS 检验；`p > 0.05` 只表示未拒绝分布相同的假设，不证明人机等价，也不单独作为“通过拟人性验证”的标准。
- 此任务支持公平分配相关的行为分布比较；没有规范信息操纵或对应真人条件，不能凭它检验规范干预效应、长期记忆或多人互动。
- 还需确定 Agent 相对直接作答的具体改变，以及开发／最终评价边界。不要反复据这 200 条答案调参，再将同一分布包装为独立验证。
