# 公开版本备份边界

日期：2026-10-16。目标仓库：`WDYXG/Intelligent-Behavioral-Cognition`。API 核验 visibility=public、permissions.push=true；用户获知后明确授权“向该 Public 仓库仅推送经审查的代码和文档”。原始任务仍要求独立审计分支、不覆盖 main/master、不 force push、不自动合并 PR。

## 纳入范围

项目自有 Python/TypeScript/JavaScript/PowerShell 源代码、必要 Schema、依赖描述和锁文件、架构/数据/实验设计文档、审计报告、最小 Python 环境描述、脱敏配置 example。源代码中指向私有数据的路径仅是引用；不意味着数据一并公开或许可扩大。

新增根 README 明示当前验证状态和代码备份边界。公开配置 example 不含选样 ID/个人属性，把真实 manifest 引用改为本地占位；禁用远端 Persona 并留空模型价格/预算，不可直接启动真实调用。旧业务配置原位不改。

`.gitattributes` 关闭自动换行转换；暂存文件与工作区文件逐项按字节核对，避免跨机签出使冻结代码 hash 失效。

## 排除范围

- 原始 ZIP/CSV/问卷/代码本全文、所有 raw/derived、未经单独公开许可审查的 working/rules。
- 个体 Persona、Evidence 微观记录、完整 cohort ID 配置、选样包、sealed targets。
- 模型请求/响应、全部历史运行目录、完整状态/记忆/轨迹与研究日志。
- `runtime/runtime.test.ts`（包含真实样本属性断言）、`runtime/initialize_personas.test.ts`（含 cohort 身份引用）；其余无身份关联的合成测试可纳入。
- 论文 PDF、模型权重、HTML 阅读/审阅导出、工作簿、临时文件、缓存、node_modules、虚拟环境。
- 本次本地细粒度证据输出与临时公开导出验收目录。

排除不删除。本地研究资产继续保留，公开 Git 不是私有数据灾备。WVS 来源 README 已记录不得再分发原始受访者记录及问卷限制；本次没有推断私人仓库或用户许可可以替代数据来源授权。规则表/字典是否可公开仍未单独完成许可复核，因此一并排除，后续有需要再审查。

## 检查方法与限制

开始时无本地 Git 历史/已跟踪文件；远端没有引用。先对 748 个适用本地文本扫描凭据模式，只记录命中文件/行号，不显示密钥；未发现候选值。原始/派生数据及二进制不作通用凭据文本扫描，因为整类禁止纳入发布。

之后逐一检查拟暂存路径、类型与大小，扫描最终候选文件中的常见密钥格式、凭据赋值、受访者 ID/个人信息、绝对用户路径和私有载荷；对历史样本断言与真实配置采取排除。检查完整暂存列表与 diff，确认全部为批准的新文件、无现有文件删除/替换，检查 `git diff --cached --check`；从暂存版本导出独立目录运行纯合成 I-A，确认公开文件集能够完成其所声明的验收。

详细暂存清单、文件哈希与检查结果留在本地 `docs/audit/evidence/`。最终分支、commit 和远端核验结果在交付回复中记录，避免在提交中自引用 SHA。模式扫描不能穷尽所有隐私/版权问题；因此采用保守数据排除，而非只凭“未命中密钥”就全部上传。

本次发布集合共 91 个文件，全部为首次纳入版本管理；公开文件集单独导出的 Phase I-A 验收为 43/43。既有代码和数据未被修复或重写，原始两项回归报错也未隐藏。
