## 优先三项

1. 确认人类参照与任务。它决定场景、操纵和拟人性指标，优先于增加 Agent 数量。
2. 修复两项过时回归夹具，并在单独授权后补最小连续决策真实验收。
3. 围绕所选任务增加最小规范条件与行为评价接口，复用已有 Persona、Decision、World 和日志。

- 私有资料以独立受控备份保存并保留原始哈希；公开 Git 不能替代数据备份。
- `runtime/source.ts` 的绝对路径恢复问题：若不能保持原布局，后续增加独立 data-root 解析配置；不修改冻结清单来伪造原路径/哈希一致。
- 未来加一项只跑合成夹具的 CI 即可，不默认跑需要真实资料的测试或任何 API 入口。
- 新代码改动后只重跑对应验收及必要回归；不要把每次审计都变为全量数据重建。
