# 本科毕业论文适配

日期：2026-10-16。题目：《智能主体的行为认知——基于大语言模型智能体的社会规范行为模拟与拟人性验证》。以下为基于现状的研究建议，未执行新实验，也不改写既有冻结方案。

## 判断

最合适的本科路线是：**先确定可合法获得、条件可对齐的人类行为参照，再选一个短程社会规范任务，复用现有 12 个 Persona 和 Python 决策—执行—反馈链，做有限的信息条件比较与群体行为分布评价。** 不需要补齐八层属性或实现规范学习。

已有工程证据支持“可记录、可执行、可追溯”的系统基础；尚无证据支持社会规范效应、人格预测效度、规范内化或真人拟人性。拟人性限定为特定任务下行为分布及情境响应的一致程度。

## 人类数据先行的任务选择门槛

当前没有完成上述门槛的数据集。已有 WVS 是人格/态度来源；PRISM 等原始资料也不能仅凭“包含人类数据”视为规范任务参照。建议先对最多 2–3 个候选数据源做小范围筛选，依据：

1. 有可合法研究使用的个体行为记录，或至少有每条件计数与样本量的可复核聚合行为分布。
2. 原始任务说明、行为选项、信息条件、收益/惩罚与反馈时序足以重建；规范操纵对应本文要比较的构念。
3. 人类样本、招募范围、任务语言和测量时间明确，能说明与 WVS 初始化人群的错配边界。
4. 目标行为能由 GM 确认执行；能隔离人类答案、派生答案和提示词例子，避免输入泄漏。
5. 使用范围与再分发权限分别核查；许可不清时不导出微观数据、不上传公开仓库。

如果只能找到同条件聚合统计，可做群体分布参照，但不能声称个体配对预测；如果连条件分母都不明，则不宜作为主要拟人性验证。若最终没有合适数据，应与导师讨论调整任务或另行设计经适当审批的人类采集，不以虚构标签补缺口。

## 建议的最小实验方案（待数据门槛后冻结）

**研究问题：** 在客观规则与行动机会固定的任务中，指定社会规范信息是否改变智能体实际执行的目标行为？该变化方向/幅度及行为分布与同条件人类参照有多大差异？

**主设计：** 一个模型、一个任务、两种信息条件。优先选择“共同任务信息”与“在共同信息上增加一种明确的规范信息”；若人类数据天然提供描述性/评价性两类且工作量允许，再加入第三条件。措辞长度、来源、可见性、奖励、处罚和动作权限尽可能匹配；不能借删除已交付反馈实现无信息条件。

**主体与状态：** 先复用既有 12 人许可视图，P/M 冻结、learning disabled；每个 `Persona × Condition × Repeat` 重置 World、X、episodes、检索暴露及任务状态。12 人仅是覆盖式开发 cohort，不是人类总体代表样本。不得跨来源拼接 WVS 个体与另一个数据集的人类身份；跨数据集比较只能明确作为任务层面/群体层面参照。

**独立单元：** 无主体交互的 trial 为独立模拟重复；有交互则以独立世界副本/组为重复单元。同一 run 的轮次和互动 Agent 不算独立样本。条件顺序随机或平衡并记录，模型实际版本/采样参数固定；服务端不支持 seed 时如实记录。重复数根据允许误差、可检测效应和预算预先确定，不先任意承诺固定调用量。

**主要行为：** 以 ActionResult 中实际执行的目标行为计分；另报请求、GM 拒绝和世界效果。API/解析/预算失败保留为工程失败，不能变成 WAIT、不帮助或直接排除后不报告。预先确定主分析分母，另报告有效运行条件下的分布和全体尝试的覆盖率。

**最小分析：** 离散行动用条件分布和总变差距离 `TV = 0.5 × Σ|p_agent(a) − p_human(a)|`；二元目标用行为率差。比较模型与人类的条件效应差 `(pA,规范 − pA,对照) − (pH,规范 − pH,对照)`，给出适合独立单元的置信区间/重采样区间。模型重复与人类参与者不能混成同一种样本。连续行为则预先选一个尺度明确的距离/误差指标，不看完结果再挑指标。

**baseline：** 至少保留一个不依赖 Persona 的简单、任务适用 baseline（如训练/开发部分确定的常数分布；不能用测试集分布拟合再在同一测试集宣称有效）。如资源允许，再比较固定简化 Persona 与当前数据驱动 Persona；该因素可后置，不要求先做全因子模型比较。数据驱动 Persona 优于简化 Persona属于待检验假设。

**解释限制：** 单模型有限任务只支持该条件下的模拟行为与人类参照一致性；相同分布不证明内部认知机制相同。规范提示影响行为不等于规范学习/内化；同调用 cognition 报告不是独立机制证据。

## 必做与不必做

本科必做：可信数据/任务合同、一个可执行场景、有限规范对照、工程失败可辨、必要重复、独立人类参照与 baseline、可核验分析与限制说明。

长期研究而非毕业前置：全部 L1–L8 属性填充、M Consolidator、规范内化机制、合成人口/DAG、跨来源个体拼接、全量 3,036 Persona、开放式小镇、任意生成式 GM、强化学习、大规模多模型矩阵、群体政策预测。

**下一步优先：人类行为数据与任务可对齐性核验。** 同期可小修两个测试夹具；确认具体任务后再补最小场景和统计接口。不要先为历史场景追加模拟，最后才寻找人类标签。
